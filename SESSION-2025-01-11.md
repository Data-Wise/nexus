## New MCP Tools Available

### `atlas_get_context`
**Purpose:** Get current work context from Atlas  
**Command:** `atlas where`  
**Returns:** Current session, project, breadcrumbs (text)  
**Usage:** "What am I currently working on?"

### `atlas_get_recent`
**Purpose:** List recent projects with activity  
**Command:** `atlas project list --format json`  
**Parameters:** `limit` (optional, default: 10)  
**Returns:** Array of projects with name, path, type, status  
**Usage:** "Show me my 5 most recent projects"

### `atlas_get_stats`
**Purpose:** Get weekly session statistics  
**Command:** `atlas stats --format json`  
**Returns:** Weekly summary, streak, hourly distribution, daily breakdown  
**Usage:** "How much have I worked this week?"

## Key Learnings

### Technical
1. **Environment Inheritance Required:** `Bun.spawn()` needs `env: { ...process.env }` to access PATH
2. **Async Process Handling:** Must `await proc.exited` before checking `proc.exitCode`
3. **Mixed Output Formats:** Handle both JSON (`--format json`) and text outputs gracefully
