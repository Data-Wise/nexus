# Printable Reference Cards

**Print these. Tape them where you work. Reference constantly.**

To print: Copy each card to a text file, use **monospace font** (Courier, Monaco, Consolas) at 10-12pt, print landscape.

## Card 4: ADHD Strategies

```
┌──────────────────────────────────────────────────────────────────┐
│                      ADHD STRATEGIES                               │
├──────────────────────────────────────────────────────────────────┤
│                                                                    │
│  🔴 WHEN OVERWHELMED → "I'm overwhelmed"                           │
│     1. Acknowledge (no guilt)                                      │
│     2. Clear mental slate                                          │
│     3. Pick the ONE thing                                          │
│     4. Break to smallest step                                      │
│     5. Do just that step                                           │
│     → Overwhelm is a signal, not a failure.                        │
│                                                                    │
│  ⚡ ENERGY MATCHING                                                │
│     🔴 Low    → "I'm low energy"                                   │
│        Inbox, file notes, read papers, admin                       │
│     🟡 Medium → "What should I work on?"                           │
│        Write drafts, review code, planning                         │
│     🟢 High   → "Deep work time"                                   │
│        New writing, complex analysis, hard coding                  │
│     → Work WITH your energy, don't fight it.                       │
│                                                                    │
│  ⏰ TIME BLINDNESS HELPERS                                         │
│     • Every task shows estimate: [15 min] [2 hrs]                  │
│     • Deadlines show "X days remaining"                            │
│     • Progress bars: ▓▓▓▓▓░░░░░ 50%                                │
│                                                                    │
│  🎯 DECISION FATIGUE REDUCERS                                      │
│     • ONE suggestion at a time (not a list)                        │
│     • Pre-prioritized by Claude                                    │
│     • "Quick wins" for momentum                                    │
│                                                                    │
│  🔄 GETTING UNSTUCK → "I'm stuck on [X]"                           │
│     1. Claude asks what's hard                                     │
│     2. Breaks into pieces                                          │
│     3. Suggests tiny first step                                    │
│     4. Offers to help draft                                        │
│     → 5 min of work > 0 min of paralysis.                          │
│                                                                    │
└──────────────────────────────────────────────────────────────────┘
```

## Card 7: Weekly Review Checklist

```
┌──────────────────────────────────────────────────────────────────┐
│                  WEEKLY REVIEW CHECKLIST                           │
│                     (15 minutes total)                             │
├──────────────────────────────────────────────────────────────────┤
│  Command: "Weekly review"                                          │
│                                                                    │
│  □ STEP 1: CELEBRATE (3 min)                                       │
│     • Review completed tasks this week                             │
│     • Acknowledge wins (even small ones!)                          │
│     "Show my completions this week"                                │
│                                                                    │
│  □ STEP 2: CLEAR (3 min)                                           │
│     • Process inbox to zero (or <5 items)                          │
│     • Each: Delete / Task / Project / Reference / Tag              │
│     "Process my inbox"                                             │
│                                                                    │
│  □ STEP 3: REVIEW (3 min)                                          │
│     • Check every active project                                   │
│     • Update stale progress numbers                                │
│     • Note any blockers                                            │
│     "Project pulse"                                               │
│                                                                    │
│  □ STEP 4: PLAN (3 min)                                            │
│     • Check next week's calendar + conflicts                       │
│     • Commit to TOP 3 priorities:                                  │
│       1. _______________________________________                  │
│       2. _______________________________________                  │
│       3. _______________________________________                  │
│                                                                    │
│  □ STEP 5: MAINTAIN (3 min)                                        │
│     • Fix orphan notes  • Tag untagged  • Date tasks              │
│     "Maintenance check"                                           │
│                                                                    │
│  WHEN: Sunday evening or Monday morning                            │
│  IF MISSED: "Catch-up review: last 2 weeks"                        │
│                                                                    │
└──────────────────────────────────────────────────────────────────┘
```

## How to Print

| Card | Best Placement |
|------|----------------|
| **1. Daily Workflow** | Tape next to monitor |
| **2. Commands** | Desk drawer / pinned |
| **3. Vault Structure** | Near desk for reference |
| **4. ADHD Strategies** | Where you see it when overwhelmed |
| **5. Research Paper** | Research notebook |
| **6. Literature Pipeline** | Near reading area |
| **7. Weekly Review** | Print weekly, fill in by hand |
| **8. Teaching** | Course binder |
| **9. Shortcuts** | Once memorized, recycle |

**Print settings**: Monospace font (Courier/Monaco/Consolas), 10-12pt, landscape orientation for best box alignment.
