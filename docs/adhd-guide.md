# ADHD Guide

**⏱️ Read: 5 min | 🧠 For: Focus, structure, low friction**

---

## TL;DR

| ADHD Challenge | Nexus Solution |
|----------------|----------------|
| Working memory overload | Externalize everything |
| Task paralysis | Claude suggests next step |
| Organization fatigue | Auto-linking, auto-tagging |
| Time blindness | Estimates on every task |
| Context switching cost | Persistent project context |

---

## Core Principle

> **Capture first, organize later.**

Don't filter. Don't categorize. Just capture. Claude handles the rest.

```
"Capture this: [thought]"
```

Note appears in `00-INBOX/`. Done. Move on.

### When Stuck

```
"I'm stuck on [task]"
```

Claude:
1. Asks what's blocking you
2. Breaks task into smaller pieces
3. Suggests tiniest first step
4. Offers to work through it

**The smallest step is still a step.**

---

### End of Day (3 min)

```
"End of day"
```

- ✅ Marks done tasks
- 📝 Captures loose thoughts  
- ➡️ Moves unfinished to tomorrow
- 📊 Shows accomplishments

| Element | Purpose |
|---------|---------|

| `[X/Y]` | Progress |
| Tables | Quick reference |

## Energy Matching

Tell Claude your state:

```
"I'm low energy right now"
```

| Energy | Task Type |
|--------|-----------|
| 🔴 Low | Process inbox, file notes |
| 🟡 Medium | Write drafts, review code |
| 🟢 High | Deep writing, new code |

## Progress = Dopamine

Every project shows:

```
**Progress**: ▓▓▓▓▓▓░░░░ 60%
**Tasks**: [3/7 complete]
**Time remaining**: ~2 hours
```

Watch the bar fill up. Feel good.

---

## Golden Rules

1. **Capture immediately** — Don't trust memory
2. **One task at a time** — Focus beats multitasking
3. **Progress > Perfection** — Done beats perfect
4. **Let Claude organize** — You generate, it structures
5. **Trust the system** — If it's in vault, it's safe

---
