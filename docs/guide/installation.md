# Installation

**⏱️ Time: 10 min**

## Vault Structure

```bash
mkdir -p ~/Obsidian/Nexus/{00-INBOX,10-PROJECTS,20-AREAS,30-RESOURCES,40-ARCHIVE,50-DAILY,60-TASKS}
```

## Plugin Installation

Download from [GitHub Releases](https://github.com/Data-Wise/nexus/releases) and place in `.obsidian/plugins/nexus/`.
