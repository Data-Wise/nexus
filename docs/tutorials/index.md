## FAQ

??? question "How long does setup take?"
    About 45 minutes for full setup. You can start using basic features in 15 minutes.

??? question "Do I need to do everything at once?"
    No! Start with morning brief + capture. Add other workflows as they feel natural.

??? question "What if I miss days?"
    No problem. Nexus catches you up with `"Catch-up review"`. No guilt required.

??? question "Can I customize everything?"
    Yes. Templates, commands, and workflows are all customizable. Start with defaults, adjust as needed.
