# Weekly Review

**⏱️ Time: 15 min | 📅 Frequency: Weekly (Sunday/Monday)**

---

## TL;DR

```
"Weekly review"
```

5 steps, 3 minutes each:

1. **Celebrate** — What got done?
2. **Clear** — Process inbox
3. **Review** — Check all projects
4. **Plan** — Set next week's priorities
5. **Maintain** — Update dashboards

---

## Before You Start

### Best Time
- Sunday evening (prep for week)
- Monday morning (fresh start)

### What You Need
- 15 uninterrupted minutes
- Claude Desktop open
- Your calendar visible

### Mindset
- This is maintenance, not work
- Don't fix things now, just note them
- Celebrate progress, even small wins

### What To Do

2. Acknowledge your progress

**Don't skip this step!** Progress recognition matters.

---

## Step 2: Clear [3 min]

### The Command

```
"Process my inbox"
```

### What Happens

Claude shows each inbox item:

```
📥 INBOX ITEM 1/8

"Need to check sensitivity bounds for P_med"
Created: 3 days ago

What should we do?
1. Delete (not needed)
2. Task (add to tasks)
3. Project note (move to P_med)
4. Reference (move to resources)
5. Quick tag (keep in inbox with tags)
```

### Quick Decisions

| If... | Then... |
|-------|---------|
| Won't need it | Delete |
| Actionable | Task |
| Project-related | Project note |
| Reference material | Resources |
| Not sure | Quick tag for now |

### Goal

Empty inbox or < 5 items remaining.

## Tips for Consistency

### Make It a Habit

- Same day, same time each week
- Block 15 min on calendar
- Don't skip even if "nothing happened"

### If You Miss a Week

```
"Catch-up review: last 2 weeks"
```

Claude adapts to cover both weeks.

### If Short on Time

```
"Quick weekly review: 5 minutes"
```

Abbreviated version:
1. Inbox count
2. Project pulse
3. Top 3 next week

---

## Quarterly Review

Every 3 months, do a deeper review:

```
"Quarterly review"
```

Covers:
- Archive completed projects
- Review areas for relevance
- Update long-term goals
- Clean up templates
