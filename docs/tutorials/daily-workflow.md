# Daily Workflow Tutorial

**⏱️ Time: 15 min to learn | 8 min daily to use**

---

## Overview

Your day has three touchpoints with Nexus:

| When | Duration | Command | Purpose |
|------|----------|---------|---------|
| Morning | 2 min | `"Morning brief"` | Orient & commit |
| During day | As needed | Various | Capture & work |
| Evening | 3 min | `"End of day"` | Close & prep |

| Quick win | Easy dopamine available |

## Part 2: During the Day

### Capture Everything

When a thought hits you:

```
"Capture: Should try bootstrap for P_med confidence intervals"
```

**Don't evaluate it. Don't organize it. Just capture.**

### More Capture Examples

| Situation | What You Say |
|-----------|--------------|
| Research idea | `"Capture: Three-way decomposition might work here"` |
| Paper to read | `"Capture: Read Tchetgen 2012 on doubly robust"` |
| Task to do | `"Task: Email collaborator about timeline"` |
| Meeting insight | `"Capture: Advisor suggested focusing Section 3"` |
| Teaching idea | `"Capture for STAT 579: Add example with real data"` |

### Getting Unstuck

When you don't know what to do:

```
"What should I work on?"
```

Claude considers:
- Your current energy (if you've mentioned it)
- Time until next meeting
- Deadline proximity
- What you've been avoiding

Returns **ONE** suggestion.

### Energy Matching

Feeling low energy?

```
"I'm low energy right now"
```

Claude suggests appropriate tasks:
- 🔴 **Low**: Process inbox, file notes, read papers
- 🟡 **Medium**: Write drafts, review code, planning
- 🟢 **High**: Deep writing, new code, complex analysis

### Context Switching

Changing tasks:

```
"Switching to grading now"
```

Claude:
- Notes your current task state
- Captures any loose thoughts
- Loads grading context

### When Stuck

```
"I'm stuck on the P_med results section"
```

Claude:
1. Asks what's specifically hard
2. Breaks it into smaller pieces
3. Suggests a tiny first step
4. Offers to help draft

## Common Patterns

### The Stuck Pattern

```
You: "I'm stuck"
Claude: What are you stuck on?
You: "[Explains]"
Claude: [Breaks it down]
Claude: What's the smallest step?
You: "[Names tiny step]"
Claude: Go do just that. Check back when done.
```

### The Overwhelmed Pattern

```
You: "I'm overwhelmed"
Claude: [Acknowledges without judgment]
Claude: Let's clear your mental plate.
Claude: What's the ONE thing that matters most?
You: "[Names it]"
Claude: Focus only on that. Everything else can wait.
```

### The Context-Switch Pattern

```
You: "Switching to grading"
Claude: [Saves P_med context]
Claude: Loading grading context...
Claude: HW5: 3 remaining, estimated 30 min.
Claude: Rubric: [[HW5-rubric.md]]
```

## Tips for Success

### Do

- ✅ Start every day with morning brief
- ✅ Capture immediately when thoughts occur
- ✅ Use time estimates to combat time blindness
- ✅ End each day with the summary
- ✅ Pick ONE thing, not three

### Don't

- ❌ Skip the morning brief
- ❌ Hold thoughts in your head "to capture later"
- ❌ Work on multiple things simultaneously
- ❌ Skip end of day (context gets lost)
- ❌ Ignore low energy signals
