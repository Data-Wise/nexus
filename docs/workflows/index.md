## Daily Flow

```
Morning (2 min)
    │
    ▼
┌─────────────────────┐
│   "Morning brief"   │
│   Pick ONE thing    │
└─────────────────────┘
    │
    ▼
During Day
    │
    ├── "Capture: [X]"      → Quick notes
    ├── "Task: [X]"         → Add tasks
    ├── "What should I do?" → Get unstuck
    │
    ▼
End of Day (3 min)
    │
    ▼
┌─────────────────────┐
│   "End of day"      │
│   Review & plan     │
└─────────────────────┘
```

---

## Weekly Flow

```
Weekly Review (15 min)
    │
    ├── 1. Celebrate completions
    ├── 2. Process inbox
    ├── 3. Review all projects
    ├── 4. Plan next week's top 3
    └── 5. Maintenance check
```
